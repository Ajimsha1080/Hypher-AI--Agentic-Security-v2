What it does

Everything your AI security
team would build — prebuilt.

Ship in days not months. Every enterprise security requirement for AI agent infrastructure, handled.

DLP + PII masking
Scans every tool call and response. Masks SSNs, credit cards, API keys, PHI before AI sees them. HIPAA mode blocks all PHI.
Human-in-the-loop approvals
High-risk operations pause for human approval. Approve/deny via dashboard or Slack. 15-minute TTL with auto-deny.
SOC 2 evidence automation
Generate a complete SOC 2 Type II evidence package at any time. 11 controls auto-documented. Auditors love this.
Shadow MCP discovery
Detect unauthorized AI agents already running in your org before you've even signed up. Best enterprise door-opener in the industry.
Real-time WebSocket alerts
Live push to dashboard. No polling. See every allow/deny, DLP detection, and HITL request the moment it happens.
A2A protocol support
Full Google/Linux Foundation A2A spec. Agent-to-agent calls are authenticated, audited, and rate-limited just like human calls.
IP allowlists + multi-admin
Restrict gateway access to your CIDR ranges. Invite teammates with scoped roles: analyst, billing, viewer. No shared secrets.
SCIM 2.0 provisioning
Okta/Azure AD auto-provisions and deprovisions users. SSO group memberships auto-map to agent policies. Zero manual work.
Quick start

Up in 60 seconds.

Point your AI agent at your gateway URL instead of the MCP server directly. That's it.

Python — LangChain integration
# Install
pip install mcpsecurity

# Wrap your existing MCP client — one line change
from mcpsecurity import MCPSecurityClient

client = MCPSecurityClient(
  gateway_url="https://acme-corp.mcpsecurity.dev",
  api_key="mcpsg_your_api_key_here",
)

# All tool calls now go through 10-layer security pipeline
result = await client.call_tool("read_file", {"path": "config.json"})
