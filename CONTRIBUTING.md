# Contributing to Hypher AI

First off, thank you for considering contributing to Hypher AI! It's people like you that make this open-source community such a great place to learn, inspire, and create.

## Getting Started

1. **Fork the repository**: Click the 'Fork' button at the top right of this page.
2. **Clone your fork**: `git clone https://github.com/your-username/hypher-ai.git`
3. **Install dependencies**: `npm install`
4. **Create a branch**: `git checkout -b feature/your-feature-name`

## Development Workflow

- Run the local development server:
  ```bash
  npm run dev
  ```
- Make your changes in the `src/` directory.
- Test your changes:
  ```bash
  npm test
  ```

## Submitting a Pull Request

1. Push your changes to your fork: `git push origin feature/your-feature-name`
2. Open a Pull Request against the `main` branch of the original repository.
3. Provide a clear and descriptive title and explain the changes you made in the PR description.
4. Ensure all tests pass and your code adheres to the project's style guidelines.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
